# Magic Shop – PHP / CodeIgniter 4

Proyecto fullstack desarrollado con PHP utilizando el framework CodeIgniter 4.

## 🧩 Descripción
Aplicación web tipo e-commerce para gestión y visualización de productos.
Incluye estructura MVC, controladores, modelos y vistas organizadas.

## 🛠️ Tecnologías
- PHP 8
- CodeIgniter 4
- HTML5
- CSS3
- JavaScript
- MySQL

## 🚀 Funcionalidades
- Gestión de productos
- Estructura backend preparada para CRUD
- Separación frontend / backend
- Arquitectura escalable

## ⚠️ Nota
El proyecto está orientado a demostración de estructura y lógica.
No se encuentra deployado debido a limitaciones de hosting gratuito con frameworks PHP.
